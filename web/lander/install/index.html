Install popkern

One command, and you're set.

Installing popkern gets you the popkern command and popkern live running on your own machine, with the full power of your computer behind it. If you just want a quick look first, you can try it in your browser with nothing to install.

macOS and Linux

Open a terminal and run:

terminal 
curl -fsSL https://popkern.dev/install.sh | sh

Windows

Open PowerShell and run:

powershell 
irm https://popkern.dev/install.ps1 | iex

Want to read the script before you run it? Good instinct! They're at popkern.dev/install.sh and popkern.dev/install.ps1.

Make your first part

Create a project, then start popkern live on your projects folder:

terminal 
popkern new my-parts/bracket
popkern serve my-parts

Then open http://127.0.0.1:7690 in your browser and start building. Everything stays on your machine.

Prefer the command line? popkern run part.rhai --step part.step builds a script straight to a STEP file.

Using an AI agent?

popkern serve also runs an MCP server, so your agent can list, edit, build, and export the same projects you're working on. For Claude Code:

terminal 
claude mcp add --transport http popkern http://127.0.0.1:7690/mcp

Stuck? Open an issue and I'll help you out.
