In development

The playground isn't live yet.

popkern is Rust, so it compiles to WebAssembly and can run the whole kernel inside a browser tab, with no server doing the geometry and nothing to install. That is what this page will become.

What it will do

  • Write a part with the popkern-part API and build it as you type.
  • Orbit the result in the browser, with the same provenance colouring the debug renders use.
  • Read the kernel's real diagnostics when an operation declines, with values and limits.
  • Download the STEP, or a mesh, straight from the page.
  • Share a link that reproduces exactly what you built.

Until then

Everything the playground will run is already in the repository, and the examples build the same parts from the command line:

shell 
git clone https://github.com/popkern-dev/popkern
cd popkern
cargo run --bin boolean_showcase
